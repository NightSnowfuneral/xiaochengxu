# 禾下美学院｜C 端 / B 端测试用例

本文档用于验收「禾下美学院知识付费」小程序与管理后台。用例按黑盒流程编写，覆盖登录、课程、支付、播放、进度、赠课、订单、配置、权限隔离与业务边界。

## 1. 测试环境与数据

### 1.1 环境要求

| 项 | 要求 |
| --- | --- |
| 后端 | FastAPI + MySQL 8.0 + Redis 7，已执行 `alembic upgrade head` |
| 小程序 | 正式 AppID + 真机；支付与真实视频播放无法在 `touristappid` 验证 |
| 管理后台 | 生产构建或 Vite 开发服 |
| 支付 | 测试商户号或预发布环境；不要在正式商户直接做大额测试 |
| 图片 | COS 桶 CORS 与公开读已配置 |
| 视频 | VOD 已开通，Key 防盗链已配置，至少 1 个可播放 FileId |
| 网络 | 真机请求域名已加入微信 request 合法域名 |

### 1.2 测试账号与数据

| 标识 | 用途 | 构造方式 |
| --- | --- | --- |
| `admin_test` | 后台管理员 | 后端首次启动以 `ADMIN_INITIAL_*` 创建；测试环境使用独立强密码 |
| 用户 A | 微信 A，手机号 `13800138000` | 小程序 A 点击「微信一键登录」并授权该手机号 |
| 用户 B | 微信 B，同一手机号 `13800138000` | 另一个微信账号，用于「同手机号自动合并」用例 |
| 用户 C | 微信 C，手机号 `13900139000` | 用于手机号冲突 / 账号隔离用例 |
| 未注册手机号 | `13700137000`（无任何账号） | 用于手机号预赠、首次登录自动认领用例 |
| 课程 P | 付费课程，价格 1 分（测试商户） | 后台创建，三张图片 + 2 个课时 |
| 课程 F | 免费/0 分课程 | 后台创建，用于价格异常验证，不用于购买 |
| 课程 G | 赠课课程 | 后台创建，用于赠课 |
| 订单 O1 | 已支付订单 | 用户 A 购买课程 P |

> 说明：课程一旦产生订单、授权或赠课记录就无法删除（`COURSE_IN_USE`），测试课程请提前规划命名，不要在生产环境随意创建。

### 1.3 优先级

- P0：上线阻断，必须全部通过。
- P1：核心业务流程，必须通过。
- P2：体验、边界与兼容性，建议通过。
